Main results

THEOREM A · STANDARD XOR ORACLE
For any polynomial \(R\), there exist a classical oracle \(O\) and a language \(L\) s.t.:
\(L\color{green}\in\color{black}\mathrm{QMA}_{1}^{O}\)
\(L\color{green}\in\color{black}\mathrm{coRP[R+1]}^{O}\)\(R+1\) adaptive rounds with one query per round
\(L\color{red}\notin\color{black}\mathrm{QCMA[R]}^{O}\)\(R\) adaptive rounds, each with exponentially many queries
THEOREM B · DETERMINISTIC FORWARD IN-PLACE ORACLE
There exist a deterministic forward in-place oracle \(\Pi\) and a language \(L\) s.t.:
\(L\color{green}\in\color{black}\mathrm{QMA}_{1}^{\Pi}\)
\(L\color{red}\notin\color{black}\mathrm{QCMA}^{\Pi}\)even with \(2^{o(n)}\) adaptive rounds, each with exponentially many queries
